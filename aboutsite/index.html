# 特别鸣谢

  • >网站搭建< 特别感谢 流萤白沙 的 ShokaX 博客搭建教学！本站很多建设和魔改部分均参考自 Noctilumina 网站，希望大家也去支持一下这位博客作者，非常漂亮的博客界面和很不错的小说撰写。
  • >网站搭建< 特别感谢 ESING 提供的 Waline 迁移 LeanCloud 数据库到 MongoDB Atlas 数据库的教学！希望大家也去支持一下ESING的小站这个博客，非常多有用的干货。
  • >网站搭建< 感谢 Shoka 和 ShokaX 作者们提供的安装和配置文档，这对建站提供很多帮助。文档链接：Shoka；ShokaX。
  • >网站搭建< 感谢 CloudFlare 提供的免费CDN设置，方便架设网站图床。之后网站也许会用 CloudFlare 大家感兴趣也可以去了解并使用它。
  • >网站美化< 特别感谢 莱特雷-letere 提供的引入 moc3 类型 Live2D 模型进入博客的方式，并提供教学文档。大家可以前往 Letere 去支持这位作者。同时感谢B站 浩劫者12345 提供的魔法纪录模型，版权归游戏开发商所有, 请不要商用！
  • >网站美化< 感谢 Osu 提供多项选择的丝滑动效设计，本站文章储物柜选择文章是以其为原型。此外，它还是个非常好玩的游戏，欢迎大家支持 Osu！
  • >网站美化< 感谢 CodePan 提供的游动小鱼效果，本站置顶页面出现的游动小鱼 Flying Fishes 源码魔改自这里（貌似不是出处，但我没有找到源码的最早出处）。
  • >网站美化< 感谢 Echarts 提供的 javascript 图标绘制库，本站置顶页面出现的统计页面的各类图表均是将 ECharts 通过 Hexo 注入的方式在 markdown 中使用，感谢其提供的精美图标绘制方法。
  • >网站美化< 感谢 Jeroen Hammann 提供的樱花飘落源代码，本站置顶页面出现的飘落花瓣效果魔改自这里 Sakura.js 这个 javascript 的插件源码。
  • >网站部署< 感谢 Vercel 提供的免费网站部署服务，本站的网站和评论系统部署都是使用 Vercel 的免费服务。
  • >网站部署< 感谢 Github 提供的 workflow 自动部署，本站的主要仓库和自动部署脚本都是通过 Github 的免费服务。
